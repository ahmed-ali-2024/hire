## 👤 المهام المطلوبة من المستخدم (User Actions Required)

لكي يعمل النظام بشكل متكامل، يُطلب من المستخدم الإجراءات التالية:
1. **تحديث ملف البيئة المحتوي على الروابط (.env):**
   تأكد من كتابة روابط الـ API الخاصة بالخدمات في ملف `.env` المحلي (مثل رابط Band API ورابط سوبابيس) بشكل صحيح.
2. **إدخال مفاتيح API الحقيقية (بعد بناء صفحة الإعدادات):**
   عند تشغيل التطبيق واكتمال صفحة الإعدادات، يجب عليك إدخال مفاتيح الـ API التالية وحفظها داخل النظام:
   * **مفتاح AIMLAPI** (لتشغيل وكلاء الفرز والمقابلة والتنسيق).
   * **مفتاح Featherless** (لتشغيل وكيل المراجعة المستقل ومحاكاة إجابات المتقدم).
   * **مفتاح Band API** (لتوثيق الرسائل والمزامنة الفورية بين الوكلاء).
3. **متابعة التطوير عبر الخطوات المتبقية:**
   يمكن للمستخدم تزويد الجلسة القادمة بملف [todo_roadmap.md](file:///media/ahmed/projects/projects/a3a_app/hire/docs/todo_roadmap.md) لتبدأ مباشرة من **المرحلة 2 (شاشة الإعدادات وحفظ المفاتيح)**.
